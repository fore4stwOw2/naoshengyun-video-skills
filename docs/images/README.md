# 截图位

`WORKBUDDY-SETUP.md` 里有三处标着「**截图位**」的引用块。补图时把对应的引用块
换成 `![说明](docs/images/文件名.png)` 即可,沿用下面的文件名就不用改别处。

| 文件名 | 拍什么 |
|---|---|
| `workbuddy-01-connectors.png` | 连接器管理页,标出右上角「自定义连接器」按钮 |
| `workbuddy-02-form.png` | 自定义连接器表单,四个字段均已填好 |
| `workbuddy-03-connected.png` | 连接器卡片显示绿点,展开可见 4 个工具 |

截图前请把 API key 涂掉或替换成 `sk-你的key`。表单那张图里的环境变量栏最容易漏。
